### 1. Helper contracts

```python
@dataclass(frozen=True)
class StreamPrestate:
    xref: int
    decoded_sha256: bytes
    dictionary: tuple[tuple[str, str], ...]

@dataclass(frozen=True)
class PagePrestate:
    contents: str | None
    streams: tuple[StreamPrestate, ...]

def vector_page_prestate(doc: fitz.Document, page: fitz.Page) -> PagePrestate: ...
def reference_counts(snapshot: bytes, xrefs: Iterable[int]) -> dict[int, int]: ...
```

- `page` is a live page of `doc`. `contents` is the exact printed top-level `/Contents` value, with `None` for an absent key. Preserve single reference, direct array, indirect-array reference, generations, and order. `streams` follows `page.get_contents()` in order. Each digest is the 32-byte SHA-256 of the decoded stream, including `b""` for a valid empty stream. A failed read is an error.
- Read object syntax with `xref_object_exact` and `exact_dict_items`. Sort dictionary keys, omit only the outer stream `/Length`, preserve array order and exact name/string spelling, and replace an indirect scalar value by its exact printed scalar. Apply the same normalization inside direct containers. Keep non-scalar references identifiable. A missing target or cycle must never normalize to an ordinary scalar. Capture the original exact items separately for writing and for detecting outgoing references, since normalization deliberately hides some references. Make rollback O-dict use this production helper. Its current `_prestate` omits `/Length` but does not resolve scalar references. [Exact-object API](C:/Users/wilson/Documents/amam_pdf_editor/utils/pdf_object_source.py:1) · [current oracle](C:/Users/wilson/Documents/amam_pdf_editor/test_scripts/vector_oracles.py:155)
- `reference_counts` returns one entry per distinct requested xref, including zero. Scan the **whole snapshot once**, including strings, stream payloads, orphans, and trailer. Match decimal object number, one or more PDF whitespace bytes (`00 09 0A 0C 0D 20`), decimal generation, whitespace, `R`. The byte before the object number must be absent or a non-digit. The byte after `R` must be EOF, PDF whitespace, or a PDF delimiter. Compare object numbers numerically. Thus `15 0 R` does not count for 5, and `5 7 R]` does. Do not use the existing dangling-reference lexer for this helper. If `b"/ObjStm"` occurs in the snapshot, the caller disables **all** in-place writes regardless of counts. A zero count also selects copy. [D20b](C:/Users/wilson/Documents/amam_pdf_editor/plans/cad-vector-object-editing.md:141)

| 1. Bind | Check the latest selection token, originating document session, and selected 1-based page. Check the document’s vector latch. Reject a stale token with `VECTOR_SELECTION_STALE`, a blocked document with `VECTOR_PAGE_UNSUPPORTED`, and an empty editable selection with `VECTOR_NOTHING_EDITABLE`. B5 currently stores only `(page_num, token, mask)` on the model. Bind the selection to its originating session and source index identity so identical pages in two tabs cannot authorize each other’s plan. |
| 2. Gate | Rebind **all** xrefs from the live page. In order, compare stream count and each decoded SHA-256, compare the six frame numbers exactly, reject repeated content xrefs or a page xref occurring other than once in `doc.page_xref(i)`, then reject an encrypted source using `doc_bytes.source_is_encrypted(doc)`, including an authenticated one. The first two checks give stale; the latter two give unsupported. Check all plan tuple lengths and the edited-slot `None` pattern before allocation. Re-encoding or renumbering alone passes if the token remains valid and decoded content and frame still match. |
| 3. Capture | Capture `before = self._capture_doc_snapshot()`, page prestate, `list(self.pending_edits)`, `edit_count`, and `secure_save_required`. Take a fresh whole-document `T0 = digest_table(doc)`. A pre-write failure returns a refusal on the original handle. Never compare against a T0 that failed to finish. |
| 4. Declare | An edited stream is in-place only if there is no `/ObjStm` marker, its snapshot count is one, the indirect `/Contents` **array**, if present, has count one, and its original dictionary has no outgoing indirect reference, including `/Length`. A single `/Contents N G R` pointing to a stream is not an array link. For all other edited slots, plan a copy. Predict append slots from `T0.xref_length` in stream order. **Before `get_new_xref()`**, reject any predicted slot targeted by `T0.dangling`. Declare `WriteSet(page.xref, in_place_xrefs, predicted_new_xrefs)`. Copied source xrefs stay outside the write set. |
| 5. Allocate and repoint | Set the transaction’s mutation-attempted flag **before** the first mutating call. For each copy, call `doc.get_new_xref()`, require the predicted xref, then `doc.update_object(new_xref, direct_dict)`. Initialize the dictionary with retained direct values and `/Filter /FlateDecode`, omitting `/Length`, `/DecodeParms`, and `/DL`. When any slot was copied, write the page’s `/Contents` **once** as a direct array with `xref_set_key_exact`. Substitute new `N 0 R` only in copied slots. Preserve original reference generations and order elsewhere. If everything is in-place, leave the original `/Contents` representation intact. |
| 6. Write and check | For each edited slot call `doc.update_stream(target, plan.new_compressed[i], compress=False)`. Finalize its dictionary with **one** `update_object` built from exact retained items, the library-produced `/Length`, and `/Filter /FlateDecode`. Omit `/DecodeParms` and `/DL` physically. Verify exact destination references, planned decoded SHA-256, single-name filter, absence of the two keys, and equality of every retained dictionary value under the specified normal form. An untouched slot keeps its xref and prestate. No GUI compression, `set_contents`, stream cleanup, garbage collection, or text-patch stream repair. |
| 7. Rule B | For a copy, count the new numbers on **post-write** garbage-zero bytes, using `serialize_document_bytes(doc, in_memory=True)` before the final live pass so any serializer side effect is covered. Require count one per new object and verify its unique position in the edited page’s direct array. An opaque snapshot cannot certify uniqueness. Take fresh `T1`; require `undeclared(T0, T1, write_set) == []`. Log offending xrefs and record `VECTOR_COMMIT_REJECTED` on failure. Its sentence is 「編輯已取消：文件的其他部分發生了預期外的變更」. |
| 8. Publish | Increment `edit_count` through its setter **once**, latch `secure_save_required = True` for delete, mark the edited page’s text index stale, call `_source_run_resolver.invalidate(page_num - 1)`, then install `plan.derived` under the new revision. Clear the previous refusal and consume the selection token. Keep `pending_edits` and fidelity protection intact. Return the result. Fallible publication belongs inside the rollback boundary. |

### 3. Rollback, revisions, and undo

- **Ordinary failure after a mutation attempt.** Call `_restore_doc_after_failed_mutation(before)` once. Reinstate the three saved bookkeeping values, clear all text indexes with `block_manager.clear()`, invalidate the full source-run cache, and discard provisional vector state. Reacquire the page from the replacement handle. Require both `vector_page_prestate(...) == prior` and `digest_table(self.doc) == T0`. The text engine supplies the capture-and-verify precedent. The whole-document delete transaction supplies the restore primitive because allocation and the page dictionary also need restoration. A raising restore retains the existing damaged-session protection. A completed restore whose verification fails latches vector editing with 「此文件在還原後與原狀不一致，本次工作階段已停用向量編輯」. Keep `vector_editing_blocked: str | None = None` and `vector_last_pass_ms: float = 0.0` per document session, including the legacy model path.
