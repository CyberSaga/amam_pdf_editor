## Goal

Make a whole-suite run **always terminate, name the hung test, keep every other result and leave evidence**, as architecture rather than habit. Measured 2026-10-22 (PySide6 6.10.2, Python 3.12.10, pytest 9.0.3): a 12 h hang sat in a native `QTextEdit.__init__` call at 0 % CPU; `faulthandler` dumped every 300 s and nothing ended the process. pytest 9's `faulthandler_exit_on_timeout` exits cleanly with no Qt, with Qt + an idle Python thread and with Qt + an idle QThread worker (3/3 each), but with Qt + a Python thread running at the kill instant it deadlocks in `ExitProcess` (5/5). Only an external `TerminateProcess` (incl. `Popen.kill()` on the `.venv` redirector) ended the process every time. So: an **external supervisor** guarantees termination (layer 1), the in-process watchdog shortens the wait (layer 2), conftest leak guards make the leaker itself red (layer 3, Phase 2).

## Phase 1 design

### 1.1 `scripts/run_suite.py` (new; the only sanctioned whole-suite entry)
- **Job model:** a job = a list of test files + one child process. Qt lane: one job per file. Pure lane: all files in one job. Both lanes go through the same supervisor, sequentially (one pytest at a time).
- **Lane classification** `classify(source_text, path)`: `qt` when the file's source matches `PySide6|^(from|import) (view|controller|main\b|src\.printing)|qt_teardown|QApplication`, else `pure`; `_FORCE_QT` / `_FORCE_PURE` override sets. Tests check the rule and overrides on synthetic source strings and never pin file counts (PITFALLS 18). Pure lane still sets `QT_QPA_PLATFORM=offscreen` (`utils/qt_deferred.py`, `utils/single_instance.py` pull in QtCore).
- **Child process:** `[sys.executable, "-m", "pytest", "-v", "--tb=short", "-p", "no:cacheprovider", "--junitxml", <out>/<job>.xml, *files, *passthrough]`, `cwd=REPO_ROOT`, env from `scripts/_pytest_env.py::clean_pytest_env()` (the blocklist and function move out of `scripts/verify_no_jump.py`, which imports them) plus `PDF_EDITOR_TEST_HEARTBEAT=<out>/<job>.heartbeat`. stdout/stderr to `<out>/<job>.log`. POSIX: `start_new_session=True`.
- **Heartbeat:** a pytest plugin module `scripts/pytest_heartbeat.py` with `pytest_runtest_logstart(nodeid, location)` / `pytest_runtest_logfinish`; when `PDF_EDITOR_TEST_HEARTBEAT` is set it appends one JSON line `{"nodeid", "phase": "start"|"finish", "t"}` atomically; without the env it does nothing. Loaded for the real suite via pyproject/conftest, loaded by the pytester test with `-p`. Single-file runs are unaffected.
- **Supervisor loop** (every 5 s):
  1. Heartbeat mtime older than `--stall-seconds` (600) or job age over `--file-ceiling` (3600) -> evidence first: `py-spy dump --native --pid <pid>` for the child and its real python child (found via `tasklist`/`ps`) to `<out>/<job>.pyspy.txt` when py-spy is on PATH; copy the heartbeat and the log tail (200 lines); then terminate the tree: on Windows every enumerated descendant by its pinned handle (creation-time checked, never a bare pid or `taskkill /T`), on POSIX `os.killpg(SIGKILL)`, then `proc.kill()`; confirm the tree is gone.
  2. Verdict: rc 0/1 normal; rc 2/3/4 failure; rc 5 -> rerun the same files with `--collect-only -q` **and the same `-m` / passthrough args**; 0 collected = OK, else failure (replaces the static rc 5 allowlist of PITFALLS 2459, which had drifted). rc outside 0..5 (negative, large unsigned Windows codes) or killed by us -> `CRASH` / `HUNG`; culprit = the last heartbeat `start` with no matching `finish`.
  3. Recovery: a HUNG/CRASH job with a pending culprit is rerun once with `--deselect <culprit>` (pure lane too); a second hang is recorded and the job stops. No heartbeat at all = collection hang: record, no rerun. Last test finished then hang (PITFALLS 2281 teardown shape): the junit was already written at sessionfinish; keep it, record the teardown hang, no rerun.
- **Aggregate:** `xml.etree` merges every `<testsuite>` into one `<testsuites>`; HUNG/CRASH become synthetic `<testcase>` + `<failure>` carrying the evidence paths and heartbeat tail. Final **one-line** summary (passed/failed/skipped/xfailed/hung/crashed/rc5-ok/elapsed); exit 1 on any failed/hung/crashed. Output dir default `.run_suite/<UTC stamp>/` (gitignored), `--out` overrides.
- **CLI:** `-m EXPR`, `--junit PATH`, `--cov` (children get `--cov --cov-append --cov-report=`; `.coverage` deleted first; afterwards `coverage xml` + `coverage report`, whose `fail_under=75` nonzero exit becomes runner exit 1), `--stall-seconds`, `--file-ceiling`, `--lane qt|pure|all`, `--files ...`, `--out`, `--no-rerun`, `--durations N` (passthrough), `--` passthrough.
- Python 3.10 compatible (CI pins 3.10). No machine paths; everything derives from `REPO_ROOT = Path(__file__).resolve().parents[1]`.

### 1.2 pyproject `[tool.pytest.ini_options]`
`faulthandler_timeout = 540`, `faulthandler_exit_on_timeout = true`: every pytest process (incl. single-file agent runs) dumps all threads after 9 min without a result and tries `_exit`; the supervisor's 10 min external kill is the guarantee behind it.
