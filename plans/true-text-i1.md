## 3. Design

### 3.1 Product: `model/text_commit/simple_font_programs.py` (new, pure bytes → facts; no fitz, no fontTools)

```
class BuiltinGlyphProof:                      # not frozen: it memoises lazy charstring scans
    program_kind: str      # "truetype" | "type1" | "unproven:<why>"  (too_large, unreadable, fontfile3, several_programs, no_notdef, post_format, hex_eexec_unreadable)
    num_glyphs: int
    def present(self, code: int) -> bool      # every present route maps code to one glyph g, 0 < g < num_glyphs (no outline test)
    def proves(self, code: int, char: str) -> bool
    def unproven(self, text: str, codes: bytes) -> int   # count of (char, code) pairs with present and not proves; counts only

def builtin_glyph_proof(program: bytes, kind: str) -> BuiltinGlyphProof    # kind in ("FontFile2", "FontFile", "FontFile3")
```

- **TrueType** (own sfnt reader: table directory walk shared with `cid_fonts` by a small helper; cmap formats 0/4/6/12 for (3,0), (1,0), (3,1); `post` 1.0 valid only when `numGlyphs <= 258` (the Macintosh standard order, prefix), 2.0 (indices + Pascal strings), missing or 3.0 = nameless, 2.5/4.0 = `unproven:post_format`; `maxp` numGlyphs; `loca`/`glyf` for outline presence = `numberOfContours != 0` (int16 at the glyph record; a composite is -1 and counts; a zero-length record is no outline)).
  - routes for a code: `(3,0)` → `[code]` else `[0xF000+code]`; `(1,0)` → `[code]`; `(3,1)` → `[code]` (MuPDF reads a lone/selected (3,1) with the code as the Unicode value). Every PRESENT subtable is a route; a present subtable that does not map the code makes the code NOT present (MuPDF would draw `.notdef` if it selected that table; no fallback, §2 row 1).
  - `present(code)` ⇔ ≥ 1 route and EVERY present route maps `code` to a gid `0 < g_i < num_glyphs` (no agreement required here: a conflicting font has the glyph, so it must reach G1′ and refuse with the new reason, not `encoding_failed`; a partial table means MuPDF may draw `.notdef`, so the code is NOT present).
  - `proves(code, char)` ⇔ `present(code)` ∧ every route maps to the SAME `g` ∧ (names present: `name_of(g)` is an exact AGL name for `char` (§AGL) and no OTHER glyph carries that name — per glyph, not whole-program) ∧ ((3,1) present: `(3,1)[ord(char)] == g`) ∧ (nameless: (3,1) present) ∧ (`char` not whitespace: outline(g)). `.notdef`/unmapped never proves. The renderer order is not modelled: agreement of every present route is renderer-independent and strictly stronger (fail closed on disagreement; twins pin it).
- **Type1** (hand-rolled): cleartext up to `eexec`; `/Encoding StandardEncoding def` → the model's StandardEncoding table (0x20–0x7E), else the vector `dup <code> /<name> put` (other codes → `.notdef`); eexec section binary or hex (PFA form, detected on the first 4 bytes; undetectable → `unproven:hex_eexec_unreadable`), decrypt r 55665 skip 4; `/lenIV` (default 4); EAGER: the `CharStrings` names in order with raw byte ranges, the `Subrs` byte ranges; LAZY (memoised per name): charstring decrypt r 4330 skip lenIV and the outline scan (`rlineto 5 / hlineto 6 / vlineto 7 / rrcurveto 8 / closepath 9 / vhcurveto 30 / hvcurveto 31` directly, or through `callsubr 10` with a LITERAL index resolved into `Subrs` to depth 8; a `callsubr` whose index is not a literal, or out of range, contributes no outline; `hsbw/sbw/endchar/hints/seac/div/callothersubr/pop` alone → no outline).
  - `present(code)` ⇔ `Encoding[code] != ".notdef"` ∧ name in `CharStrings`. `proves(code, char)` ⇔ present ∧ exact AGL name ∧ (non-whitespace: outline). gid for the consistency story = CharStrings index with FreeType's `.notdef` swap; no `.notdef` → `unproven:no_notdef`.
- **AGL** (model-side `_AGL_ASCII`: the 95 names of 0x20–0x7E, parity-tested against `fontTools.agl.UV2AGL`) plus `uniXXXX` / `uXXXX[X[X]]` exact forms; any `.suffix` variant, ligature or multi-character name is not an AGL name for `char`.
- **Program choice**: exactly one of `FontFile`/`FontFile2`/`FontFile3` on the descriptor, else `unproven:several_programs`; `FontFile3` → `unproven:fontfile3`; size > `_MAX_FONT_PROGRAM_BYTES` → `unproven:too_large`; any parse error → `unproven:unreadable`. An `unproven:*` proof has `present` False for every code (the font refuses `encoding_failed` at the first encode check, like an unreadable face today).

### 3.2 Product: `FontCapability` (fonts.py), planner, dto, view
