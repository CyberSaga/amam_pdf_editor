## Current state and next step
- Status: continuous-page and thumbnail process routes implemented, NOT accepted; default thread and retained lists remain unchanged.

- Full suite remains owner-paused. Do not call this complete from helper or wire tests alone.

## Contract and scope
- Preserve existing watermark rendering helper, page coverage, annotation handling, rotation/crop/UserUnit, color conversion and render clamps.
- Freeze descriptors and snapshot under the same GUI-thread revision; no worker-side second strip/bake.
- Reject malformed/nonfinite/oversized recipes and fall back to the existing overlay-aware path; never silently omit overlays.
- No retained DisplayList for covered pages initially. Uncovered pages can retain the ordinary path.
- Transport validates the bounded recipe and ties readiness to its hash. Pending generations must not reuse another recipe under the same key.
- Thread fallback uses the same frozen pair. Thumbnail currency must include the document source, including buffered delivery, while returning credits exactly once.
- Save-attempt maintenance and structural Undo/Redo must invalidate any stale source even if a save later fails.
- Existing source stripping failures are parity cases, not permission to repair or alter the user's document here.

- Work spans controller page/thumbnail routing, render-worker DTO/protocol/client/worker, shared Qt-free raster and focused tests. No changes to editing, watermark semantics or normal preferences.
